Все три `POST`-эндпоинта возвращают одинаковый объект.

```json
{
  "id": 184756,
  "action": "scrobble",
  "progress": 92.0,
  "watched_at": "2026-08-16T19:24:11Z",
  "show":    { "title": "Severance", "year": 2022, "ids": { "imdb": "tt11280740" } },
  "episode": { "season": 2, "number": 1 }
}
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | `number` | ID записи о воспроизведении |
| `action` | `enum` | `start` · `pause` · `scrobble` · `checkin` |
| `progress` | `number` | Прогресс, который зафиксировал сервер |
| `watched_at` | `string` | ISO 8601, когда отмечен просмотр. Приходит при `action: "scrobble"` |
| `expires_at` | `string` | ISO 8601, когда истекает сессия |
| `movie` / `show` + `episode` | `object` | Тайтл в том виде, в каком его распознал MyShows |

::tip
---
icon: i-lucide-scan-search
---
**Сверка распознавания.** Возвращённый объект тайтла полезен для проверки: если MyShows
распознал не то, что вы отправили, это видно сразу.
::

::warning
---
icon: i-lucide-circle-help
---
**Уточнить на бэкенде.** Что возвращает `/stop`, когда `progress` ниже порога. У Trakt
в этом случае приходит `200` с `action`, отличным от `"scrobble"` — то есть по
HTTP-статусу засчитанный просмотр от незасчитанного не отличить. Если у нас так же,
здесь нужен явный абзац «как понять, что просмотр засчитан»: это первое, что спросит
интегратор.
::
